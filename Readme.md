# Kahani AI

**Kahani AI** is an AI-powered storytelling platform that allows users to generate rich, visually engaging stories using both **text and images**, all created with the help of **Generative AI**. Whether you want to create a children's tale, an educational narrative, or a fictional adventure, Kahani AI brings your stories to life with beautiful visuals and compelling language.

---

## 📁 Project Structure

Kahani AI is split into **two main parts**:

- 🎨 **Frontend** — the user interface for creating and viewing stories
- 🧠 **Backend** — the AI engine that generates story content and images

---

## 🚀 Getting Started

### 🖥️ Running the Frontend

1. Open your terminal.
2. Navigate to the `frontend` folder:  cd frontend
3. Start the React development server: npm start

### ⚙️ Running the Backend
1. Open a new terminal window.
2. Navigate to the `backend` folder: cd backend
3. Run the backend server: python main.py
3. Make sure you have all necessary dependencies installed (such as Flask, FastAPI, or any others required by main.py).
